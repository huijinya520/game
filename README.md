# 最后一道红线 · 重返蓝天

**[点击在线游玩](https://huijinya520.github.io/game/)** · [完整游戏剧本](cinematic-web/docs/故事剧本.md) · [Word 剧本](cinematic-web/docs/最后一道红线-故事交互版剧本.docx)

我是刚到工厂的协调员。一架飞机的最后检查还没做完，客户已经在门外等。我得走到现场，看看大家缺什么。

根据 Guillaume Faury 人物资料与真实时代背景改编的第一人称互动游戏。三幕依次经历交付受阻、疫情停摆和工厂复工；每次时代转换有简短背景介绍，随时能查看当前目标。无需航空或管理知识。

![机库调查](cinematic-web/docs/preview.webp)

- 五个操作环节：机库走访、工程队派遣、员工承诺、应急预算、三天复工调度。
- 七种结局，只有“接力的人”能得到最高 100 分。其他结局会显示行动如何影响分数。
- 所有操作仅需点击，没有现实倒计时，可在确认前调整。支持自动存档、手机触屏、投影大字和减少动态。
- 写实电影风格，通过分层景深与交互视差表现 3D 感，属于轻量 2.5D 网页场景。

完整新版位于 [cinematic-web](cinematic-web/)。技术与课堂说明见该目录 README。原始上传资料与其他作业不公开；具体人物事件、游戏资源、对白、结局及评分为创作，来源边界见剧本末尾。

## 开发

Node.js 20+，没有第三方运行依赖，不需要安装 npm 包。

```sh
npm start
npm test
npm run build
```

构建生成静态网站和 [单文件备用版](cinematic-web/play-offline.html)。规则测试覆盖七种结局与唯一满分、逐步存档、资源约束、跨天复工逻辑及 300 条不同组合路线。

旧版位于 Git 历史，早期课堂版本仍保留在 `classroom-publish/site/`。
