# 最后一道红线：故事交互版

一通电话带来两份相互矛盾的记录。你通过人物对白和可拿起的物件理解故事，决定自己的行动。没有倒计时、答题分数或专业知识测验。后台记住之前的决定，改变后续人物反应和七种尾声。

## 课堂展示

打开已发布的网页，点击“接起这通电话”。点击“继续”推进对白；亮着的物件可以查看。所有物件都能用点击操作，不要求找隐藏像素、拖拽或解谜。

右上角设置可开启“投影大字”和“立即显示对白”，以及全屏、环境音和减少动态。可随时停下来讨论。“快进这段”跳到当场行动；“刚才说的话”可回看。进度存放在本浏览器，清除浏览器数据会移除存档；禁用存储仍可以连续游玩。

一次路线有 15 个场景、13 次决定，设计阅读时长约 15–25 分钟，取决于阅读与讨论速度。切换设备不共享进度。

## GitHub Pages

首次发布如提示 Pages 未启用，仓库所有者需要在 [Pages 设置](https://github.com/huijinya520/game/settings/pages) 中将 **Build and deployment → Source** 选为 **GitHub Actions**，然后在 [发布工作流](https://github.com/huijinya520/game/actions/workflows/pages.yml) 点击 **Run workflow**。

等待 `Publish` 任务成功，并使用该任务返回的部署 URL。预期为 `https://huijinya520.github.io/game/`。不要把仓库链接或预计网站地址当作已部署成功的证明。

## 单文件备用

`play-offline.html` 内嵌所有画面和代码。可从 GitHub 文件页选择 Download raw file，保存后用浏览器打开。GitHub 的源码预览不会运行 HTML。网盘、聊天附件预览可能禁用脚本，应在浏览器中打开真正的 HTML 文件。

文件不依赖 CDN、在线字体、登录、服务器 API、语音服务或视频。自动存档依赖浏览器是否允许本地文件使用存储；不允许时仍可玩完当前路线。

## 开发和测试

```sh
npm start
npm test
npm run build
```

Node.js 20+；开发服务器默认端口 3000，可用 `PORT` 覆盖。源码 `story.js` 管理人物、场景、条件对白与结局；`app.js` 管理交互、画布、音效和存档。构建生成单文件与 `dist/` 静态网站。

可选浏览器验收脚本：安装 Python Playwright 和 Chromium 后，先启动服务器，再执行 `GAME_URL=http://127.0.0.1:3000/ python tests/browser_smoke.py`。脚本的 Chromium 路径可以通过 `CHROMIUM` 覆盖。

自动规则测试覆盖七种结局、场景连接、分支人物反应、存档校验及 1,000 次不同路线。浏览器测试覆盖七种真实点击路线、刷新续玩、390 px 手机界面、大字、禁用存储、损坏存档与美术加载失败。

## 性能与美术

`assets/scenes.webp` 是 2 × 3 的六场景图集，`assets/cast.webp` 是 3 × 2 的六人物图集。网页使用的两张图片合计约 0.58 MB，完整首次加载的静态资源约 0.65 MB（压缩传输前，准确字节见构建文件）。离线 HTML 因 Base64 内嵌略大。

画布像素密度上限 1.5，环境粒子约 30 帧/秒更新，页面不可见时停止粒子绘制。减少动态模式关闭视差、浮动和粒子。采用 2.5D 分层与 CSS 透视，不加载 WebGL 引擎、大型三维模型或视频。低性能设备可以关闭动态；实际加载和帧率仍取决于网络、设备与浏览器。

六个环境按行排列：雨夜办公室、晨光机库、玻璃会议室、工厂食堂、空机库、日出董事会。人物按行排列：玩家、马修、维克多、艾琳、克莱尔、戏剧化 Faury。美术由生成工具制作，经过格式压缩，未使用真实人物照片作为剧情证据。

完整改编剧本、虚构边界与背景来源见 [故事剧本](docs/故事剧本.md)。原始上传文档及其他课程作业不包含在公开目录中。
