# 最后一道红线 · 重返蓝天

以第一人称经历“交付受阻 → 疫情停摆 → 工厂复工”。主要根据用户提供的《G 2 - Guillaume Faury.pdf》提取主题，结合真实时代背景，创作具体人物、交付和行动。

## 直接开始

**[在线游玩](https://huijinya520.github.io/game/)**。进入网页点击“走进我的第一天”。开场用简短背景卡解释我是谁、出了什么事、眼前先做什么。2020 年与复苏阶段再次出现背景卡，右上角随时可查看“我现在要做什么”。

玩家不需要航空或管理知识。操作只用点击，支持触屏与键盘焦点。调查没有隐藏像素，资源安排可以在确认前修改，没有真实倒计时。首次出现的供应商、短工时和独立复核均有日常语言解释。

五个可操作环节：四处地点走访三处；派出两支工程队；推动两项员工承诺；安排七枚应急筹码；完成三天复工调度。另有会面分支与对话决定，前面的行动会改变后来的人手、配件、对白与路线。

## 七种结局，唯一满分

只有“接力的人”获得最高 100 分。其余六种结局的分数来自实际行动，结尾展示六项得分与原因。评分衡量报告保护、技术人才、共同协商、资金安排、完成复核的交付，以及持续改进。反复调整卡片不扣分。

三幕共 13 个场景，一条路线 12 个场景。设计游玩时间约 20–30 分钟，因阅读与讨论速度不同而变化。课堂可开启设置中的“投影大字”“立即显示对白”和全屏，也可以关闭声音与动态。

## 开发与验证

Node.js 20+，无第三方运行依赖，不需要安装 npm 包。

```sh
npm start
npm test
npm run build
```

默认开发端口 3000，环境变量 `PORT` 可覆盖。`story.js` 同时保存场景与确定性的调查、资源、调度和评分规则。`app.js` 负责画面与操作。构建输出 `dist/` 与自包含的 `play-offline.html`。

规则测试包括七种结局、唯一 100 分、每一步存档重放、调查次数、预算、互斥方案、采购与复核的跨天规则、班组上限，以及 300 条不同组合路线。可选 Python Playwright 浏览器验收：先启动服务器，再执行 `GAME_URL=http://127.0.0.1:3000/ python tests/browser_smoke.py`；Chromium 路径可由 `CHROMIUM` 覆盖。

## 显示与性能

使用六场景和六人物 WebP 图集，约 0.58 MB。通过分层透视、景深、鼠标视差、雨线与飞机进度动画表现 3D 感，实际为轻量 2.5D 场景，无自由行走三维地图、视频或真人配音。无外部字体或 CDN。画布像素密度上限 1.5，粒子约每秒 30 次更新，后台暂停粒子绘制。

本版存档键为 v5，避免误读前版进度。关闭页面后可继续；浏览器不允许存储时会明确提示，仍可完成当前游玩。

## 发布与备用

GitHub Actions 运行规则测试与构建后，将 `dist/` 发布到 GitHub Pages。首次设置见仓库 Settings → Pages → Source → GitHub Actions；之后推送主分支自动发布。

`play-offline.html` 包含全部程序与美术，可从 GitHub 文件页 Download raw file 保存，再用浏览器打开。原始上传 PDF 和其他课程作业不包含在公开站点中。
